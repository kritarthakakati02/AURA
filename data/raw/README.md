# Cached Source Data

Files in this directory are generated by `python -m benchmarks.prepare_dataset` from immutable upstream commits.

- `gsm8k_train.jsonl` is from OpenAI's GSM8K training partition at commit `3101c7d5072418e28b9008a6636bde82a006892c`; `GSM8K_LICENSE.txt` contains the MIT notice downloaded from that same commit. The official GSM8K test partition is not cached or used.
- `mbpp_training.jsonl` contains only upstream MBPP task IDs 601-974, the training range documented in the Google Research README. Official MBPP validation, test, and few-shot task IDs are filtered before local persistence. Its source file is the Google Research repository at commit `0eebfd403ba438bfd14cb70b9b24a7745c997083`.

The MBPP dataset card declares CC-BY-4.0, while the containing Google Research repository has an Apache-2.0 LICENSE. See `data/processed/DATASET_CARD.md` for both declarations, attribution details, and the remaining licensing review note. Do not remove provenance or license notices when redistributing cached data.
